Projeto Conecta

Conectando Clientes, Lojistas e Prestadores


Uma plataforma unificada desenvolvida para simplificar as relações comerciais e de prestação de serviços de forma ágil, segura e centralizada.

A Solução

Para o Cliente

Catálogo de produtos, adição ao carrinho com controle via CarrinhoService e histórico completo de compras em um clique.

Para o Lojista

Gestão autônoma de catálogo, controle de estoque e acompanhamento do status de pedidos em tempo real.

Para o Prestador

Espaço para divulgar serviços, receber orçamentos e gerenciar a disponibilidade profissional.

Destaques do Aplicativo

✓

Autonomia B2C e B2B: Clientes têm autonomia de compra enquanto lojistas gerenciam ativamente o faturamento e status de entrega.

✓

Integração em Tempo Real: Uso robusto de banco de dados NoSQL para garantir que os pedidos cheguem aos lojistas no exato instante da compra.

✓

Filtros e Categorias: Organização intuitiva de navegação para que o usuário final encontre comidas, produtos e serviços rapidamente.

Tecnologias Utilizadas

Criamos uma plataforma rápida e confiável combinando ferramentas modernas:

Flutter

A engrenagem do portal. Framework que nos permitiu criar uma interface nativa, bonita e fluida para Android e iOS a partir de um único código.

Firebase (Firestore & Auth)

Nosso cofre de dados seguro. Funciona como centralizadora de autenticação e banco de dados em tempo real para a gestão de estado dos pedidos.

Desafios & Lições

Desacoplamento de Lógicas

Desafio: Mapear e sincronizar fluxos de compras complexos sem poluir a interface.
Lição: Implementação de Services (como o CarrinhoService) para isolar a regra de negócios do visual do Flutter.

Segurança e Privacidade

Desafio: Garantir que lojistas diferentes não tenham acesso a pedidos de concorrentes.
Lição: Uso estrito do Firebase Security Rules para proteger a integridade e privacidade dos dados.
