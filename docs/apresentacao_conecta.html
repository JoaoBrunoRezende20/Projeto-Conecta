Conecta
Aplicativo Multi-Perfil

Projeto Conecta

Uma plataforma unificada desenvolvida para conectar Clientes, Lojistas e Prestadores de Serviços. Desenvolvido com Flutter e Firebase, o app oferece uma experiência ágil, escalável e segura para gestão de produtos e atendimentos.

Visão Geral

A Nossa Solução

O aplicativo suporta diferentes níveis de acesso, cada perfil com funcionalidades e permissões distintas rodando na mesma base de código.

  • ✓ Para o Cliente: Explorar o catálogo, adicionar ao carrinho e realizar compras.
  • ✓ Para o Lojista: Gerenciar produtos, acompanhar estoque e mudar os status de pedidos.
  • ✓ Para o Prestador: Oferecer serviços e gerenciar orçamentos.

Integrado ao Firebase

"Nosso objetivo é aproximar o comércio local do usuário final de forma intuitiva e sem atritos operacionais."

Perfil: Cliente

Jornada de Compras

O consumidor final tem uma experiência focada na conversão rápida, com buscas otimizadas e acompanhamento transparente.

  • ✓ Filtros Avançados: Categorias dedicadas (ex: Comidas) para encontrar o que precisa.
  • ✓ Carrinho Inteligente: Gestão de itens integrada via CarrinhoService com cálculo automático de taxas.
  • ✓ Histórico Completo: Transparência total sobre pedidos passados e em andamento.
Perfil: Lojista / Prestador

Gestão de Negócios B2B

A plataforma entrega autonomia para que os parceiros gerenciem seus negócios diretamente pelo aplicativo.

  • ✓ Catálogo Próprio: Adição, edição e inativação de produtos no estoque.
  • ✓ Gestão de Pedidos: Transição fluida de status: Aceito, Em Preparo, Saiu para Entrega.
  • ✓ Painel Independente: Módulos desacoplados garantindo carregamento rápido.
Arquitetura Técnica

Tecnologias Utilizadas

A base do projeto foi escolhida para garantir estabilidade, segurança de dados e fácil manutenção.

Flutter (Dart)

Framework nativo do Google, garantindo que o app rode de forma suave e com design de ponta tanto em Android quanto iOS com uma única base de código.

Firebase (Google)

Utilizado para autenticação (Auth) e banco de dados em tempo real (Firestore), entregando os pedidos no mesmo segundo em que são feitos.

Regras de Negócio Isoladas: O CarrinhoService é o motor que garante os cálculos precisos sem travar a interface.
